# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

Wanderer is a **Hugo theme** for travel/outdoor blogs. It adds map rendering,
GPX track display, photo galleries, geo-tagged taxonomy pages, and site
statistics on top of a standard Hugo blog.

## Architecture

### Layout System

Hugo's standard lookup order applies. All layouts are in `layouts/`.

### JavaScript Modules (`assets/js/`)

All JS assets are fingerprinted (cache-busted) at build time via Hugo's `resources.Get` + `fingerprint "md5"`.

Vendored into `static/`:
- `leaflet-awesome-markers/` — custom marker icons
- `svelte-grid-gallery/` — compiled Svelte gallery component (CSS + JS)

### Map Tile Provider

Mapy.com is the tile provider. Requires `params.mapyCzApiKey` in `config.yaml`. Get a key at https://developer.mapy.com/account/projects.

### Taxonomies

Three taxonomies are used: `categories`, `tags`, `trips`. The `trips` taxonomy
groups posts into ordered series — `single.html` shows `tripIndex / tripCount`
in the post title if the post belongs to a trip.

### Content Structure for Posts

```
content/posts/my-post/
├── index.md          # front matter + text
├── images/           # triggers auto-gallery (disable with hide_gallery: true)
│   └── *.jpg
└── gpx/              # triggers auto-map with elevation profile
    └── *.gpx
```

Image metadata (order, featured flag, captions) goes in the front matter
`resources:` block. The image with `params.featured: true` is used as the
post's representative image in list views.

### Tag Geolocation

`data/tag_locations/located.yaml` maps tag names to `{lat, lng}`.
`data/tag_locations/ignored.yaml` lists tags to exclude from map rendering.
These feed the full-page map layout.

### Geonet (Experimental)

A geographic network built from GPX tracks. Pass `geonetPath` in a map page's
front matter pointing to a pre-built GeoJSON file. Renders as an interactive
network graph overlaid on the map.

### i18n

Translation strings in `i18n/en.yaml` and `i18n/cs.yaml`. Add new UI strings there.

### Search

Full-text search uses a JSON index at `/index.json` (generated by
`layouts/index.json`). The `outputs.home` config must include `json` for search
to work.

### Media Index

An optional `MediaIndex` output format produces `mediaindex.json` — a list of
all media attached to pages. Requires `outputs.home` to include `MediaIndex`
and the `outputFormats.MediaIndex` block in `config.yaml`.
